## ⚡ Overview

A lightweight, responsive web presence designed for high readability and fast initial paint times:
* **Proof of Work & Ventures (`ProofOfWork.tsx`, `Portfolio.tsx`):** Structured catalog of past projects, hackathon prototypes, and technical ventures.
* **Investor Angle & Storytelling (`InvestorAngle.tsx`, `Story.tsx`):** Focused founder narrative articulating personal inflection points and market convictions.
* **Integrated Meeting Scheduling (`BookMeeting.tsx`):** Frictionless scheduling portal for engineering peers, collaborators, and investors.
* **Supabase Integration:** Realtime database connectivity via `@supabase/supabase-js`.

---

## 🛠️ Tech Stack

- **Core:** React 18, TypeScript, Vite
- **Data & Auth:** Supabase Client (`@supabase/supabase-js`)
- **Styling:** Tailwind CSS, Lucide Icons

## 💻 Local Development

```bash
# 1. Clone repository
git clone https://github.com/mdroushanalam-astra/Mypersonalwebsite.git
cd Mypersonalwebsite

# 2. Install dependencies
npm install

# 3. Launch server
npm run dev
```
